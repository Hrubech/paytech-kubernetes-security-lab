# Contribuer au projet

Merci de contribuer à l'amélioration du laboratoire pédagogique PAYTECH.

## Proposer une amélioration

1. Ouvrir une Issue en décrivant le contexte, le problème et la proposition.
2. Pour une correction technique, fournir les versions de Kubernetes, kind et du CNI testées.
3. Créer une branche dédiée.
4. Tester les manifestes sur un cluster jetable.
5. Ouvrir une Pull Request avec les résultats de validation.

## Attentes

- Expliquer le risque de sécurité traité.
- Préserver la reproductibilité du TP.
- Ne pas ajouter de vrais secrets ou données personnelles.
- Mentionner les prérequis et incompatibilités éventuelles.
- Privilégier la documentation officielle.
- Ne pas présenter un contrôle comme effectif sans test.
